# مساعد البنك 🏦

موقع يساعد البنكي في لعبة الشوارع (نسخة لندن العربية): يسجل فلوس كل لاعب، البطاقات، البيوت والفنادق، الرهن، وكل عملية في سجل.

- كل شي ينحفظ في الجهاز تلقائيا (يقدر يكمل اللعبة بكرة)
- تصوير الطاولة وحفظ الصورة مع اللعبة
- آلة حاسبة
- تراجع عن أي عملية غلط
- تعديل أسماء وأسعار البطاقات من داخل الموقع

البيانات الافتراضية (أسماء وأسعار البطاقات) في `data.js`.
